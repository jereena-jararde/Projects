# Projects
Smart Task Manager:
This project implements a task management system using an array, queue, and stack to handle task storage, processing, and undo operations. It demonstrates the practical application of FIFO and LIFO principles in a real-world task scheduling scenario.

Supermarket Billing Queue:
This project simulates a supermarket billing system where customers are managed using a queue, their items are stored in an array, and a stack is optionally used for item reversal. It showcases how data structures model real-life billing and service processes.
